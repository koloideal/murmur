# murmur

**murmur** — лёгкая личная «экосистема» между Android-телефоном и wayland-ноутбуками: уведомления телефона на десктопах, телефон как обычный системный плеер, один общий буфер обмена. Без общей локалки, без VPN, без сторонних координаторов — только тупой релей на твоём сервере, а всё содержимое зашифровано сквозным ключом.

murmur — это **«самый тихий»**, **«самый приватный»** и **«самый модульный»** способ сделать из твоих устройств одну машину.

```
  телефон (Kotlin-агент) ──WSS──▶ murmur-server ◀──WSS── murmurd × N ноутов
                                   тупой релей              Arch / Hyprland
```

Телефон — тонкий фоновый агент: он только сообщает события и выполняет команды. Вся логика и весь интерфейс живут на ноутбуках, в твоём собственном стиле: уведомления падают в твой notification-демон, а телефон выглядит обычным MPRIS-плеером — медиаклавиши, `playerctl` и виджеты бара работают сами.

## ✨ Возможности

-   **Синхронизация уведомлений**: уведомления телефона появляются на всех живых ноутах; закрытие где угодно гасит везде — включая сам телефон.
-   **Управление медиа в реальном времени**: то, что играет на телефоне, отражается как родной MPRIS-плеер — метаданные, позиция, обложка, play/pause/prev/next/seek.
-   **Общий буфер обмена**: ноут ↔ ноут и ноут → телефон автоматически; телефон → ноут по твоему явному действию (share-меню / меню выделения) — прилетает на тот ноут, за которым ты сидишь.
-   **Сквозное шифрование**: один семейный ключ, XChaCha20-Poly1305. Релей видит только шифротекст, id устройств и тайминги.
-   **Отзыв устройств**: у каждого устройства свой auth-токен — потерянное выкидывается мгновенно, семейный ключ ротируется.
-   **Выбор активного узла**: ноуты сами договариваются, за каким ты сидишь, по состоянию lock/idle — без координатора и без эхо-штормов в буфере.

## 📦 Пакеты

| Пакет | Стек | Роль |
|---|---|---|
| `server/` | Rust | `murmur-server` — тупой авторизованный релей. Только live, ноль хранимого контента. |
| `laptop/` | Rust | демон `murmurd` (фича = модуль) + CLI `murmurctl`. Вся настройка — только терминал. |
| `mobile/` | Kotlin | Фоновый агент: notification/media-слушатели, share и selection-таргеты. |
| `shared/` | Rust | `murmur-proto` — конверт, крипто и типы сообщений, общие для сервера и ноутов. |

## 🚀 Быстрый старт

```console
# релей (на домашнем сервере, за любым TLS-терминатором)
$ cd server && cargo build --release

# демон ноута + CLI
$ cd laptop && cargo build --release

# приложение — открыть mobile/ в Android Studio или
$ cd mobile && ./gradlew assembleRelease
```

## 📌 Дизайн

Всё — флоу пейринга, формат конверта, выбор активного узла, правила дедупликации буфера — описано в [DESIGN.md](DESIGN.md).

Добавить фичу в `murmurd` — это: новый файл с конструктором `feature()`, одна строка в реестре и один вариант `Message` в `murmur-proto`.

## 📄 Зачем?

KDE Connect нужна общая локалка. Apple Continuity нужна Apple-экосистема. Tailscale нужен их координатор. murmur не нужно ничего из этого — только сервер, который уже твой, и он не может прочитать ни байта из того, что через него проходит.
